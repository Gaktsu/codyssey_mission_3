## 7. 체크리스트

### 7.1 데이터 구조

- [ ] n×n 2차원 패턴/필터 저장
- [ ] 특정 위치 값 저장·읽기
- [ ] 3×3, 5×5, 13×13, 25×25 처리

### 7.2 모드 1 입력 처리

- [ ] 필터 A, B를 한 줄씩(공백 구분) 입력받아 저장
- [ ] 저장 확인 출력 후 패턴 입력
- [ ] 행/열 개수 불일치, 숫자 파싱 실패 시 안내 문구 + 재입력

### 7.3 모드 2 JSON 로드 및 스키마 검증

- [ ] filters(size_5, size_13, size_25) 로드
- [ ] 패턴 키에서 N 추출 → size_N 필터 선택
- [ ] 필터/패턴 크기 일치 검증, 불일치 시 케이스 FAIL + 사유 (비정상 종료 없음)

### 7.4 라벨 정규화

- [ ] expected: '+' → Cross, 'x' → X
- [ ] filter 키: 'cross' → Cross, 'x' → X
- [ ] 출력과 PASS/FAIL 비교를 표준 라벨로 수행

### 7.5 MAC 연산

- [ ] 반복문으로 위치별 곱셈 + 누적합 직접 구현 (NumPy 금지)
- [ ] 점수를 float로 반환

### 7.6 점수 비교 정책

- [ ] abs(a - b) < 1e-9 이면 동점
- [ ] 모드 1: A / B / 판정 불가
- [ ] 모드 2: Cross / X / UNDECIDED, expected와 같으면 PASS

### 7.7 성능 분석

- [ ] 크기별 MAC 연산 10회 반복 평균(ms) 측정
- [ ] I/O 제외, 연산 함수 호출 구간만 측정
- [ ] 표: 크기(N×N) / 평균 시간(ms) / 연산 횟수(N²)
- [ ] 모드 1은 3×3, 모드 2는 3×3·5×5·13×13·25×25 출력

### 7.8 결과 리포트 (콘솔 + README)
